# 国信金工中证500指数增强策略本地回测项目

本项目是针对国信证券金融工程研报《基于风险预算的中证500指数增强策略》中，主动量化策略（超预期精选组合）在米筐本地开源回测引擎 **`RQAlpha`** 上的回测复现框架。

项目利用米筐的 `rqdatac` 数据接口获取 A 股股票的历史日线行情与基本面财务数据，并在每月月底（调仓日）基于因子库打分，动态筛选出中证500成分股中得分最高的 30 只股票等权构建指数增强持仓。

---

## 1. 项目文件结构
*   `config.json`: 回测参数与时间配置（开始时间、结束时间、基准代码等）。
*   `data_fetcher.py`: 负责封装米筐 `rqdatac` 的数据获取接口，进行成分股与财务快照数据的提取。
*   `factors.py`: 负责计算基本面 3 因子（打分过滤前60只）与技术面 5 因子（精选前30只）的打分逻辑。
*   `main.py`: 主入口，注册 `rqalpha` 策略回调函数（`init` 和 `rebalance` 调仓任务），启动米筐回测并输出每日净值对比图。

---

## 2. 安装依赖
在运行回测前，请确保您本地的 Python 环境已安装了以下包：
```bash
pip install pandas numpy matplotlib
```
以及米筐的数据和回测框架：
```bash
pip install rqdatac rqalpha
```

---

## 3. 初始化回测数据包 (Bundle)
由于米筐 `rqalpha` 本地回测需要历史行情数据包的支持，若您是初次在本地运行 `rqalpha` 可能会遇到 `bundle path not exist` 的错误。请在终端执行以下命令进行数据包下载和更新（仅需在初次运行时执行一次）：
```bash
rqalpha update_bundle
```

---

## 3. 运行回测
您只需在项目目录下执行以下命令即可启动米筐引擎驱动的策略回测：
```bash
python main.py
```

回测执行完毕后：
1. 控制台将直接打印出经典的 **RQAlpha 绩效分析报告**（含累计收益率、年化收益率、夏普比率、信息比率、跟踪误差等）。
2. 在该项目文件夹下会生成一张 **`backtest_result.png`** 业绩曲线对比图。
3. 该图片也会自动复制到您的电脑桌面上，名称为 **`策略回测净值业绩图.png`**，方便您直接双击查看。
